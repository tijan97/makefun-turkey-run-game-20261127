Gobble Run is a fast autumn runner in which you play a turkey fleeing Thanksgiving dinner: sprint from the farmyard through the barn and past the kitchen, jumping roaring ovens, sliding under swinging carving knives, grabbing corn for points, and ducking into haystacks to hide while the farmer chases you with his pitchfork — outrun him for 1500 metres to slip through the forest gate, or get caught and try again with a harder, faster run.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. SPACE or click jumps (twice for a flap), ↓ slides, H hides in a haystack, M mutes, P pauses.
